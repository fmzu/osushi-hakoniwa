# 新種6体追加 設計書

## 解決する課題

現在12種でメジャーな寿司ネタを網羅しており、全種なかよしにすると図鑑が埋まって「集める楽しさ」が終わる。図鑑の枠を広げて「まだ埋まっていない」を作り、再訪の動機を作る。

## 方針

**純粋追加（アプローチA）**: +6種を SPECIES 配列にデータ追加するだけ。出現ロジック・図鑑UI・セーブ形式に仕組み変更なし。巻き物Shape（新シルエット）は次回以降のイテレーションで検討する。

### レアリティ構成（全18種）

| レア | 既存 | 追加                 | 計  | 重み |
| ---- | ---- | -------------------- | --- | ---- |
| ★    | 5    | 2 (ほたて,さば)      | 7   | 6    |

`RARITY_WEIGHT = {1:6, 2:3, 3:1}` は据え置き。種数増加に伴い個別種の出現率は自然に下がるが、レアリティ層ごとの出現比率は維持される。

### えびと大えびの差別化

- えび（既存★★）: NIGIRI + EBI_TAIL オーバーレイ（尻尾飛び出し）。オレンジ系。
- 大えび（新★★★）: NIGIRI。ぼたんえびらしい鮮やかな赤/オレンジ/白のパレット。EBI_TAIL オーバーレイは別パターン（大きめ/形違い）にするか無しにするかはドット絵プレビューで判断。ネタ部分の色の豪華さ + ★★★レア演出で差別化。

## 影響範囲

### 変更するファイル

| ファイル                  | 変更内容                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `src/species.ts`          | SPECIES 配列に 6要素追加（既存 `Species` 型をそのまま使用）                                                  |
| `src/sprites.ts`          | 新種のドット絵（16x16 グリッド + パレット）を追加。大えび用に BOTANEBI_TAIL オーバーレイを追加する可能性あり |
| `src/pickSpecies.test.ts` | `SPECIES.length` のアサート更新（12→18）。新種のレアリティ分布テスト追加                                     |

### 変更しないファイル（自動対応）

- `src/constants.ts` — `ZUKAN_PAGE_SIZE=6` 据え置き
- `src/types.ts` — `Species` 型は変更不要
- `src/world.ts` — `pickSpecies` のレアリティ重み抽選は種数非依存（ループ）
- `src/zukan.ts` — ページング（`Math.ceil(SPECIES.length / ZUKAN_PAGE_SIZE)` で自動3ページ化）・3状態・★表示は種数非依存
- `src/store.ts` — `seen`/`friends`/`greet` は Set/Record で ID ベース。新 ID は自動で扱える
- UI/DOM/CSS — 変更なし
- `src/main.ts` — 変更なし

### セーブ互換性

旧セーブ（`osushi-zukan-v2`）に新種の ID が含まれていないだけ。新種は未発見状態（影絵）で表示される。既存のなかよし記録・あいさつ回数・壁設定はすべて保持。移行ロジックの変更は不要。

## ドット絵の制作方針

1. 既存種のグリッド+パレット形式（`sprites.ts` の NIGIRI/GUNKAN Shape + 1文字パレット）をそのまま使用
2. 各種の特徴色でパレットを設定
3. ドット絵を生成後、全18種を並べたプレビュー画面（HTML Artifact）で確認 → オーナーの承認を得てから反映
4. 大えびの尻尾オーバーレイ（BOTANEBI_TAIL）の採否はプレビュー時に判断

## 検証方法

- `vp check src/` エラー0
- `vp test run` 全パス（pickSpecies のアサート更新含む）
- `vp build` 成功
- `vp dev` でブラウザ確認: 18種が出現する / 図鑑3ページ / 新種のドット絵が正常描画 / 既存種のセーブが保持される
- ヘッドレススモーク: `speciesCount=18` / `initialSushis=3` に更新して確認
