# おすしのはこにわ

## 概要

ドット絵のお寿司たちがイモムシみたいにむにむに歩き回る、依存ゼロ・HTML 1枚の箱庭ゲーム。お寿司との出会いを集める「図鑑埋め」が遊びの核。

## 解決する課題

1. **誰の・どんな課題か**: 作者が「図鑑を埋める系のゲームを作ってみたかった」という創作願望を持っていた。実用ツールではなく、作る楽しさ・育てる楽しさそのものが目的
2. **なぜ既存ツールでは不十分か**: 既存の収集ゲームを遊ぶのではなく、自分の作品として育てたい。Claudeアプリで生まれた作品を引き継いで成長させる題材でもある
3. **導入前後の変化**: 前: アイデアがチャット内のアーティファクトで完結 / 後: GitHub Pagesで常時遊べて、図鑑が日々埋まっていく自分のゲームになる
4. **放置すると何が困るか**: 作品がチャット履歴に埋もれて消える。また、HTML/JS/レスポンシブ/アクセシビリティの生きた学習教材を失う

## 機能一覧

### 実装済み（v2まで）

- お寿司が尺取り虫方式で歩き回る箱庭（16x16ドット・2フレーム）
- ネタ6種（サーモン・まぐろ・たまご・えび・いか・いくら軍艦）
- せいかく6種が挙動パラメータ（歩くテンポ・休憩率・♡率・Uターン率）に直結
- 図鑑（プロフィール帳風）: タップで「はっけん！」登録、localStorage保存

### v3（今回の開発スコープ）

1. **ネタを12種に拡張 + レアリティ3段階**
2. **2段階図鑑「みかけた / なかよし」**（タップ登録を置き換え）
3. **来店制 + 呼び鈴**（タップスポーンを置き換え）
4. **えびにしっぽ追加**（おうぎ尾デザイン）
5. **セーブデータの自動移行**

## v3 詳細仕様

### ネタ構成（12種・レアリティ3段階）

| レア度 | ネタ | 出現の重み |
|---|---|---|
| ★ ふつう | サーモン・まぐろ・たまご・たこ（新）・納豆（新・軍艦） | 高 |
| ★★ めずらしい | えび・いか・いくら・あなご（新）・えんがわ（新） | 中 |
| ★★★ とってもレア | うに（新・軍艦）・とろ（新） | 数%（重み付き抽選） |

- 新規6種は既存方式（共通グリッド + パレット差し替え + 必要ならオーバーレイ）で追加。配色はブラウザモックアップで選定済み
- うに・納豆・いくらは軍艦グリッド、その他はにぎりグリッドを使用
- 図鑑にレア度を★表示する

### 2段階図鑑「みかけた / なかよし」

- 箱庭に来店した時点で自動的に「**みかけた**」になる → 図鑑のシルエット（影絵）が姿に変わる。プロフィール（なまえ・せいかく）は？？？のまま
- タップ＝「あいさつ」。せいかくごとに決まった回数あいさつすると「**なかよし**」→ プロフィール解放 + 「なかよしになった！」バナー
- なつきやすさ（あいさつ必要回数）はせいかく連動。目安: あまえんぼ2回 / のんびりや・こうきしんおうせい3回 / せっかち・ねぼすけ4回 / はずかしがりや6回（あいさつすると逃げる素振り）
- 図鑑ヘッダーに「みかけた n/12・なかよし n/12」の2進捗を表示
- 図鑑マスの3状態: 未見＝シルエット（影だけ・「何かいる」感）→ みかけた＝姿が見える（プロフィール？？？）→ なかよし＝プロフィール解放
- ★★★の初「みかけた」時はバナー演出を強化（キラキラ・「レアはっけん！！」）

### 来店制 + 呼び鈴

- タップでのスポーンは**廃止**。タップの役割は「あいさつ」に一本化
- 開いている間: 一定間隔（目安60〜120秒に1回の抽選）でふらっと来店。満員（14匹）なら来ない。ときどき退店もする
- 留守中の来店: 最終訪問時刻をlocalStorageに保存し、再訪時に経過時間に応じて来店処理（目安20分に1匹、上限あり）。「るすのあいだに来てたみたい」表示
- **呼び鈴ボタン🔔**: 押すと数秒後に1匹来店。クールダウン約90秒（ボタンに残り時間表示）
- 出現抽選はレアリティの重み付き。数値はすべて実装後に遊んで調整する

### えびのしっぽ

- ブラウザモックアップで選定済みの「**A: おうぎ尾**」を採用
- えびの濃色系（#FF8662 / 縁 #EE9476）で、ネタ後端から斜め上に開く尾扇。付け根が細く先端が広がる
- 伸びフレーム・縮みフレームの両方に位置調整して実装。左右反転にも対応
- `tools/generate_sprites.py` のスプライトデータにも反映する

### セーブデータの自動移行

- 旧形式: `osushi-zukan` キーに発見済みID配列 `["salmon", ...]`
- 新形式（例）: `osushi-zukan-v2` キーに `{ seen: [id], friends: [id], greet: {id: count}, lastVisit: timestamp }`
- 起動時に旧キーがあれば: 旧発見済みID → `seen` と `friends` の両方に登録（既存の発見を「なかよし」として引き継ぎ、進捗を失わせない）。移行後も旧キーは削除せず残す（ロールバック可能性のため）

## 画面仕様

- 既存レイアウトを踏襲（ピンクのフレーム + canvas + 下部バー）
- 下部バーに追加: 呼び鈴ボタン🔔（クールダウン中は残り秒数表示）
- 図鑑モーダル: 2進捗表示・★表示・シルエット表示を追加
- バナー: 「みかけた！」「なかよしになった！」「レアはっけん！！（強化版）」「るすのあいだに来てたみたい」

## データ永続化

- localStorage のみ（`osushi-zukan-v2`）。保存失敗時はメモリのみで動作継続（既存方針を踏襲）

## 技術構成

- 言語: HTML + CSS + JavaScript（単一ファイル `index.html`、依存ゼロを堅持）
- スプライト: 文字列グリッド + パレット差し替え、起動時にcanvasへベイク（既存方式）
- 補助ツール: `tools/generate_sprites.py`（Pillow）でPNG/GIFアセット生成
- 公開: GitHub Pages（main ブランチ直公開）
- iso.html（アイソメ版）は今回触らない

## テスト観点

自動テストは書かない（おもちゃ規模のため。コスト vs リスク判断）。Push前に手動チェックリストで確認する:

- 正常系: 来店が発生する / あいさつ回数到達で「なかよし」になる / 呼び鈴で1匹来てクールダウンが効く / 図鑑の2進捗・★・シルエットが正しい
- 異常系: localStorage が使えない環境でも動く（プライベートブラウジング）
- **移行**: 旧 `osushi-zukan` データがある状態で開く → 発見済みが「なかよし」として引き継がれる
- エッジケース: 満員時に来店しない / リロード後に進捗が保持される / 留守中来店が上限を超えない

## 開発体制

- 開発はこのリポジトリで直接行う。Claudeアプリ（アーティファクト）での編集は今後行わない（衝突防止）
- ドット絵も既存フォーマット（文字列グリッド + パレット）で作成する
